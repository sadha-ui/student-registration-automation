# Student Registration Automation

## Project Overview
An automated student registration system built using n8n and Google Sheets.

## Technologies Used
- n8n
- Google Sheets
- Workflow Automation

## Workflow
1. **Form Trigger:** Collects student registration details.
2. **Edit Fields:** Organizes and processes the submitted information.
3. **Google Sheets:** Automatically stores student details in a spreadsheet.

## Features
- Online student registration form
- Automatic data processing
- Google Sheets integration
- Automatic insertion of registration records

## Future Enhancements
- Automated confirmation emails
- Administrator notifications
- Duplicate registration detection

## How to Run
1. Import the exported JSON workflow into n8n.
2. Configure your Google Sheets credentials.
3. Connect your own spreadsheet.
4. Test the workflow using sample registration data.
